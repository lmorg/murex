## v7.4.xxxx

### Features

* terminal: add OSC 133/633 terminal integrations with prompt and command markers, working-directory reporting, VS Code shell integration, and Ttyphoon command output blocks
* examples: add an example demonstrating directed acyclic graphs

### Bug Fixes

* expressions: fix parsing of negative variables ([issue #1005](https://github.com/lmorg/murex/issues/1005), [@tiymat](https://github.com/tiymat))
* expressions: safely handle empty array subshells and invalid function output ([issue #1010](https://github.com/lmorg/murex/issues/1010), [@SAY-5](https://github.com/SAY-5))
* ANSI: correct common escape-code constants, including CRLF ([issue #1007](https://github.com/lmorg/murex/issues/1007))
* expressions: handle errors from logical-NOT variables without nil dereferences ([issue #1003](https://github.com/lmorg/murex/issues/1003))
