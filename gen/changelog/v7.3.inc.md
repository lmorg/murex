## Breaking Changes

Support following platforms have been deprecated:
* Windows running 32bit ARM
* Go versions 1.25 and below

You may have success building against these deprecated targets, however they are no longer part of the automated test and deployment pipelines.

## v7.3.xxxx

### Features

* expressions: support for logical-not variable syntax via `!$(variable)`
* integrations: ttyphoon dictionaries added
* integrations: force-TTY integrations reintroduced
* integrations: Ttyphoon prompt events now include environment variables
* dep: dependency updates, including `golang.org/x/image` and readline refreshes

### Bug Fixes

* expressions: avoid panic when comparing arrays with numbers
* expressions: fix panic in comparison operators with non-comparable types
* core: close stdin after write in unmarshal
* integrations: fix `su root` execution regression ([issue](https://github.com/lmorg/murex/issues/987))
* app: fix `define-force-tty-func` summary handling
* core: revert duplicated-code regression
* tests: improve expression coverage
* `which`: don't search the current directory for bare command names
* events: run `onPrompt` callbacks in the background
* expressions: fix handling of invalid named regexp symbols
* `ansititle`: sanitize ANSI escape sequences
